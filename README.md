# cs300-assignment-1
CS300 HTML & CSS Component
By: Javier Aranda

Component Option: Option B - Product Card (Life Size Lego Pikachu Listing)
Inspired by a generic interface when buying an amazon product/facebook marketplace post
Live Site URL: https://javiarnd.github.io/cs300-assignment-1

## Design Choices/Notes
Displays three images side-by-side using CSS Flexbox.
Utilizes RGBA background styling and border radius to create a high-contrast text area.
Features a CSS transition that reveals an original strikethrough price upon hovering.
Integrated with Google Fonts (`Raleway`).
Semantic document structure (`<main>`, `<header>`, `<section>`, `<footer>`).
